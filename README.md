## 📦 Установка
Через окно Package Manager:
1. Открой **Window → Package Manager**
2. Нажми **+** → **Add package from git URL...**
3. Вставь URL:
```
https://github.com/Ohenzy/state-machine-ugl.git?path=/Assets/Scripts/StateMachine/#v2.0.0
```
